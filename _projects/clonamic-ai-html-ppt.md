`/clonamic-ai-html-ppt` 명령 하나로 브라우저에 편집기가 열립니다. 별도 AI 서비스나 API 키 없이, 터미널에서 쓰던 AI가 그대로 편집기의 AI가 됩니다.

- 16:9 슬라이드부터 A4 문서까지, 도형·효과·오토 레이아웃을 캔버스에서 직접 편집합니다.
- AI 탭 채팅, 요소를 골라 한 줄로 요청하는 인라인 수정(⌘J), 포커스 핀(⌘⇧J)으로 AI에게 맡깁니다.
- AI는 덱을 덮어쓰지 않고 바꿀 속성만 바꿉니다. 요청 단위로 한 번에 되돌릴 수 있습니다.
- 캔버스에서 본 그대로 페이지별 또는 전체 PDF로 내보냅니다.

## 설치 (Claude Code)

```
/plugin marketplace add clonamic/plugin
/plugin install clonamic-ai-html-ppt@clonamic
```
