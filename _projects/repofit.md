인기 있는 오픈소스가 내 프로젝트에도 맞는지는 문서와 코드를 직접 봐야 알 수 있습니다. RepoFit은 후보를 찾고, 쓰던 에이전트로 도입 여부와 적용 위치를 검토하도록 돕습니다. [사이트](https://repofit.seoddh.chatgpt.site/)에서 바로 볼 수 있습니다.

- **트렌딩**: 오늘·이번 주·이번 달 GitHub 트렌딩을 보고, 쉬운 소개·활용 예시·장단점·공식 출처를 담은 해설을 읽습니다.
- **스킬**: 누적 설치 상위 300개 스킬의 한국어 설명, 작업 분류, 적용 방법과 예상 효과를 확인합니다.
- **내 프로젝트**: 공개 레포와 후보, 개선 목표를 입력해 검토 요청을 만들고, 도입 판단·근거·파일별 제안·검증 상태를 확인합니다.
- **내 에이전트**: RepoFit에 연결한 에이전트에 분석을 요청해, 접근 가능한 작업 기록을 바탕으로 활용 보고서와 맞춤 스킬·적용법을 받습니다.

![RepoFit 스킬 화면]({{ '/assets/img/repofit-skills.jpg' | relative_url }})

## 사용 전 참고

- 사이트에서 요청을 준비한 뒤 에이전트 대화에 보내면 실행됩니다. 프로젝트 검토는 RepoFit 스킬을 추가하고, 활용 분석은 RepoFit MCP에 연결해 사용합니다.
- 모델 실행에는 내 에이전트 계정과 사용 조건이 적용됩니다.
- 요청은 검토 전용입니다. 코드 수정과 스킬 자동 설치는 하지 않습니다.
